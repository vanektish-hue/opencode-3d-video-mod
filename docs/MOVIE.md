# Фильм «Как ИИ собрал это видео» — как он устроен

Этот файл описывает **сам фильм** (~10 минут), который собирает мод Creator, и
пайплайн, которым он строится. Всё — от 3D-моделей до субтитров, музыки и
вотермарки канала — сгенерировано кодом, без сторонних редакторов.

Весь рассказ ведётся **от первого лица — от лица самой нейросети** («я — нейросеть»).
Рекламы в ролике нет: вместо неё — честный блок поддержки автора канала **miphik**
на Boosty (ссылка в описании). Вотермарка канала (`miphik`) висит в нижнем правом углу.

Готовый файл: `exports/movie.mp4` (1280×720 @ 24 fps, H.264 + AAC).
Субтитры: `exports/movie.srt`. Описание с главами: `exports/movie.description.txt`.
Обложка: `exports/thumbnail.png`.

| Артефакт | Что это |
| --- | --- |
| `exports/movie.mp4` | готовый фильм, **630.0 с (10:30)**, 1280×720, h264+aac |
| `exports/movie.srt` | субтитры-реплики (для YouTube) |
| `exports/movie.description.txt` | описание + **30** глав с таймкодами |
| `exports/movie.chapters.ffmeta` | главы в формате ffmetadata (вшиты в mp4) |
| `exports/thumbnail.png` | обложка 1280×720 |

Проверено: длительность **10:30**, блок поддержки начинается на **178.8 с (2:58)**,
в mp4 вшито **30 глав**, звук во всех сценах (mean ≈ −19…−21 dB). Озвучки сцен
нигде не накладываются друг на друга (это проверяется тестом).

## Конвейер за 8 шагов

```
script.js            сценарий: 31 реплика от лица нейросети + визуальный план
   │
   ▼
tts.py / voice.js    edge-tts (Microsoft Neural): mp3 + тайминги каждого слова
   │                 → narration.json (длительности, word-boundary marks)
   ▼
build.js             раскладка таймлайна: сцены, «биты», переходы, блок поддержки
   │
   ├─ clips.js       рендер 3D-клипов (орбитальная камера) → PNG-секвенции
   ├─ music.js       процедурная музыка и SFX (синусы/шум, без ассетов)
   ├─ audio.js       декод озвучки, даккинг музыки под голос, сведение → WAV
   └─ субтитры       группировка слов в реплики → movie.srt
   │
   ▼
video.js             один ffmpeg filter_complex: xfade + drawtext + overlay +
                     subtitles(libass) + loudnorm → movie.mp4
```

Ключевая идея: **озвучка задаёт тайминг**. Сначала синтезируется вся речь и
измеряются длительности, потом под них подгоняются визуальные сцены, субтитры и
музыка. Поэтому картинка, голос и текст всегда синхронны.

### Удержание: сцены-«биты»

Длинные сцены разбиваются на несколько визуальных **битов** (`planBeats`): внутри
одной реплики картинка «режется» быстрыми внутрисценными переходами (`wipeleft`,
`smoothleft`, `wipeup`…), а фон каждого бита меняет оттенок (`shade`) и тип
анимации. Текст при этом лежит в **глобальных оверлеях с абсолютным временем** и
не перезапускается на каждом бите — поэтому длинная сцена не «зависает».

### Тайминг: переходы не «съедают» голос

Сцена живёт ровно **озвучка + пауза** (`GAP` = 0.5 с). xfade-переходы накладывают
соседние сегменты друг на друга и тем самым «съедают» время из сцены, поэтому при
раскладке каждая сцена автоматически удлиняется ровно на длительность своих
переходов (`buildLayout`). Без этого следующая реплика начиналась бы раньше, чем
закончилась предыдущая, и голоса накладывались бы друг на друга. Переходы между
сценами — плавные (0.65 с), внутри сцены — 0.5 с; на каждом стыке остаётся
заметная пауза, поэтому голос не «срезается» переходом.

## 3D-модели

Все модели — процедурные, из примитивов (`src/movie/models.js`):

| модель | из чего |
|--------|---------|
| mouse | roundedBox-корпус, тори-колесо, капсулы, LED (emissive) |
| mug | цилиндр + тори-обод + tube-ручка + диск «кофе» |
| controller | roundedBox + капсулы-рукоятки + стики + d-pad + кнопки |
| headphones | tube-дуга + цилиндры-чашки + тори-амбушюры |
| phone | roundedBox-корпус + экран (emissive) + камеры |
| house | бокс + 4-гранная пирамида-крыша + дверь/окна |
| dice | roundedBox + точки-сферы |
| robot | торс/голова/руки/ноги, светящиеся глаза |
| planet | сфера + континенты-эллипсоиды + кольцо + луна |
| rocket | конус-нос, цилиндр-корпус, кили, светящееся пламя |

Клипы рендерятся CPU-растеризатором (`raster.js`) при 1280×720, `samples=1`,
`aa=2` (истинное супер-сэмплирование, без сабкадрового размытия) и мягким
**headlight** — фронтальным светом вдоль камеры, чтобы облетаемая модель всегда
была освещена со стороны зрителя. Растеризатор z-буферизован. Отсечение задних
граней (**back-face culling**) **не используется**: генераторы примитивов
расходятся в направлении намотки треугольников (`makeBox` наружу, `paramSurface`
внутрь) и в направлении авторских нормалей (сфера/цилиндр наружу, тор внутрь),
поэтому любой универсальный знак отсечения либо дырявит корпус, либо показывает
внутренности. Все поверхности непрозрачны, поэтому рисуются обе стороны, а
z-буфер выбирает ближнюю — модели плотные и непрозрачные, без «просвечивания»
сквозь корпус. Затем клипы собираются в видео 1280×720.

## Звук

- **Голос** — два многоязычных нейросетевых голоса (Microsoft Edge Neural TTS):
  `en-US-AndrewMultilingualNeural` (мужской) и `en-US-AvaMultilingualNeural`
  (женский), темп **+20 %**. Алиасы `dmitry`/`svetlana` сохраняют чередование
  мужской/женский из сценария (переопределяются через `MOVIE_VOICE_MALE`,
  `MOVIE_VOICE_FEMALE`, `MOVIE_RATE`). Слова приходят с таймингами.
- **Музыка** — процедурная lo-fi подложка: прогрессия Am–F–C–G, бас, арпеджио,
  мягкие барабаны (`src/movie/music.js`).
- **Даккинг** — музыка автоматически приглушается на время речи (огибающая по RMS).
- **SFX** — whoosh на переходах, «динь» на главах, riser перед блоком поддержки.
- Финальный микс нормализуется и проходит `loudnorm` (−16 LUFS) в ffmpeg.

## Блок поддержки и вотермарка

Рекламы в ролике **нет**. На **третьей минуте** (≈2:58) идёт честный блок:
сцена `supportlead` («рекламы у меня пока нет») и `support` («поддержи автора на
Boosty — ссылка в описании»), после — `resume` («продолжаем»). Никаких
«рекламных» полос, отсчётов и циановой айдентики — обычный дружелюбный сегмент.

В нижнем правом углу всё видео висит **вотермарка канала** — `miphik`
(`CHANNEL` из `src/movie/script.js`). В нижнем левом — маленькая подпись `creator mod`.
Логотип-кольцо из старой версии убран.

## Как собрать

```sh
cd opencode-3d-video-mod

# 1) озвучка (нужен Python + edge-tts), пишет tmp/movie/narration.json
node scripts/movie-voice.mjs

# 2) посмотреть раскладку без рендера (длительности, блок поддержки, главы)
node bin/movie.js --dry

# 3) полная сборка -> exports/movie.mp4 (+ movie.srt, movie.description.txt)
node bin/movie.js                 # качество: crf 21, preset medium
node bin/movie.js --fast          # черновик: crf 24, preset veryfast
node bin/movie.js --hq            # максимальное качество: crf 19
node bin/movie.js --reuse         # не перерендеривать уже готовые 3D-клипы
```

Флаги: `--dry` (только раскладка), `--reuse` (переиспользовать клипы),
`--fast` (быстрый пресет), `--hq` (crf 19), `--no-chapters` (без вшивания глав).

## Зависимости

- Node ≥ 20; `ffmpeg-static` / `ffprobe-static` (собственные бинарники ffmpeg).
- Python 3 + `edge-tts` — только для озвучки (можно заменить на SAPI-фолбэк).
- Шрифты — из `C:\Windows\Fonts` (для субтитров и текста).
